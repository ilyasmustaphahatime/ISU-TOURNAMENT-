Organizer Fixtures Guide

This guide explains, in a simple human way, how organizers should use the Manage Matches dashboard to create fixtures, update final scores, postpone games, cancel matches, and keep the tournament website accurate.

1. Create the fixture 2. Update the result later 3. Add player stats after the match
Quick Rule

How Organizers Should Think About Fixtures

A fixture starts as a scheduled match. When the game is finished, you do not create a second match. You go back to the same match and update it using the same Match ID. That is the most important idea to remember.

Field Guide

What Every Field Means In Manage Matches

Match ID

A unique number for the match. Use the same number later if you want to update that exact match.

Status

Use scheduled before kickoff, played after full time, postponed if delayed, and cancelled if removed.

Match Date

The day the game is planned to happen.

Match Time

The kickoff time for the fixture.

Home Team Number

The team number of the home side. It must already exist in the teams list.

Away Team Number

The team number of the away side. It must already exist in the teams list.

Referee ID

Optional. Use it only if you already manage referee records.

Home Goals

The final number of goals scored by the home team. Keep it at 0 before the match is played.

Away Goals

The final number of goals scored by the away team. Keep it at 0 before the match is played.

Step By Step

How To Create A New Fixture

1

Open Manage Matches

Go to the organizer dashboard and find the Manage Matches panel.

2

Choose A New Match ID

Pick a match number that is not already being used.

3

Set The Match As Scheduled

In the Status field, choose scheduled.

4

Add The Time And Teams

Enter the match date, match time, home team number, and away team number.

5

Leave The Score At Zero

Before kickoff, keep Home Goals and Away Goals at 0.

6

Save The Match

Click Save Match. The fixture will now appear in the website schedule.

Example: Creating A Fixture

Match ID: 1001
Status: scheduled
Match Date: 2026-04-02
Match Time: 18:00
Home Team Number: 3
Away Team Number: 5
Home Goals: 0
Away Goals: 0
After Full Time

How To Update The Result Of A Played Match

Step 1

Use The Same Match ID

Do not create a new match for the same game. Reuse the original fixture’s match ID.

Step 2

Change The Status

Set the Status to played.

Step 3

Enter The Final Score

Fill in Home Goals and Away Goals with the final result.

Step 4

Save Again

Click Save Match again. This updates the fixture and also affects the league table.

Example: Updating The Final Result

Match ID: 1001
Status: played
Home Goals: 2
Away Goals: 1
Special Cases

How To Postpone, Cancel, Or Delete A Match

Postponed

If the match will happen later, use the same match ID and change the status to postponed.

Cancelled

If the match is removed completely, use the same match ID and change the status to cancelled.

Delete Match

If the match record itself is wrong, enter the match number in Delete Match ID and click Delete Match.

Important Follow Up

What Organizers Must Do After Saving A Played Match

Add The Player Stats

After the result is saved, go to Manage Player Stats and enter the goals, assists, yellow cards, red cards, and clean sheets for the players involved.

Check The Dashboard

Refresh the dashboard and review: Fixtures, League Table, Top Scorers, Top Assists, and Clean Sheets.

Common Mistakes

What Usually Goes Wrong

Creating a second match instead of updating the first one

Always reuse the same match ID when the fixture already exists.

Using the wrong team number

If the home or away team number is wrong, the fixture will be attached to the wrong clubs.

Forgetting to change the status to played

If the match stays as scheduled, the league table will not update from that result.

Simple Matchday Routine

The Best Practical Workflow For Organizers

Before Kickoff

Create the fixture, check the teams, and make sure the match is marked as scheduled.

After Full Time

Update the same match to played, save the final score, then enter the player stats.

End Of Day

Review the dashboard and make sure the league table and leaderboard highlights match the real matches.
